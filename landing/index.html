Features

从题目物料到数据回收，
每个环节都为二次开发留了接口

不是一套写死的问卷工具，而是一个可插拔的调研系统框架。

▦

题型物料库

题目、设置器、公共组件全部物料化，B/C 两端共用。通过 questionLoader / setterLoader 动态装载——新增一种题型，就是新增一个物料包，这是二次开发扩展的核心位置。

单选 / 多选填空评分矩阵级联投票NPS日期
⌘

逻辑编排引擎

可视化编排显示逻辑与跳转逻辑，logicEngine 在 C 端实时求值，复杂问卷不再靠问卷创建者写代码。

◉

AI 生成问卷

一句自然语言描述，流式生成完整问卷 schema。接入自己的 LLM 服务，密钥只在服务端。

⛨

安全能力内建

传输加密、敏感词检测、发布审查、投票防刷、富文本 XSS 过滤、接口级权限守卫——默认开启，不是选配。

⧉

空间与协作

Workspace 多角色权限 + 问卷级协作者管理，团队协同与多租户场景开箱即用。

↧

数据回收与分析

分题统计、选项计数、数据导出下载任务、消息推送 Hook（答卷入库即触发 webhook）。答卷数据从回收、统计到推送的链路完整闭环。

Architecture

前后端分离的单仓架构

两个独立子工程各自管理依赖，通过 nginx 网关组合为一个整体对外服务。

WEB / MPA

Vue 3 + Vite 5

  • management B 端：编辑、发布、分析
  • render C 端：答题页，预览复用
  • materials 两端共用题型物料库
  • ElementPlus · Pinia · 按需自动引入
→
SERVER / API

NestJS 10 + TypeORM

  • 9 大业务模块，统一 /api 前缀
  • Authentication / Survey / Workspace 守卫
  • 安全插件机制：响应加密、脱敏
  • 统一异常码 + 全局限流
→
DATA / OPS

MongoDB + Docker

  • TypeORM 实体，事务与聚合
  • 本地开发内置内存 Mongo，零依赖启动
  • nginx 反代 /api 与静态资源
  • 多阶段构建，slim / full 双镜像

默认端口链路：浏览器 → nginx :8080 → NestJS :3000 → MongoDB :27017

Quickstart

三条命令，跑起完整系统

本地开发无需安装 MongoDB——内存数据库随服务自动启动。

01
克隆仓库Node ≥ 18 · npm ≥ 8.6
git clone https://github.com/didi/xiaoju-survey.git
02
启动服务端自动拉起内存 MongoDB · :3000
cd server && npm install && npm run local
03
启动前端Vite dev server · :8080
cd web && npm install && npm run serve

→ 管理端 http://localhost:8080/management · 答题端 http://localhost:8080/render/:surveyPath

Deploy

生产环境，一个 compose 文件

MongoDB 与应用镜像一键拉起，密钥全部走环境变量注入。

# 配置数据库与密钥后，一条命令启动 export MONGO_INITDB_ROOT_USERNAME=admin export MONGO_INITDB_ROOT_PASSWORD=******** export XIAOJU_SURVEY_JWT_SECRET=******** docker compose up -d # 镜像版本：slim（生产）/ full（调试） # 对外服务：http://localhost:8080

运行时镜像内 nginx 托管前端静态资源，并将 /api、/exportfile、/userUpload 反代到本机 NestJS 服务。

XIAOJU_SURVEY_MONGO_URL
MongoDB 连接串
XIAOJU_SURVEY_JWT_SECRET
JWT 签名密钥（必填）
XIAOJU_SURVEY_RESPONSE_AES_…
答卷响应加密密钥
AImodel_API_URL / KEY
接入自有 LLM，启用 AI 生成
PORT
服务端端口，默认 3000
